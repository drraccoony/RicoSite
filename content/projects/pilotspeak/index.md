Straight forward, Help yourself fit in with the commerical pilot crowd with this generator. Talk the talk! Simply chooses random words from several pre-defined arrays and piecing them together using `array_rand()`. Also uses some javascript to copy text to the users clipboard via a button press. Keeps track of usage via a flat file totalgens.txt via a super easy `intval()` function.

Check out the tool here: https://drraccoon.me/pilot/
Example output:

- The night recurrent on my check ride while based in NY was in question by my chief pilot.
- The crew meals on the 737 MAX during my last trip was super f^$ked up.
- The reserve trips on the 737 last month was against ALPA regulations.
